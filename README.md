# 🧠 Task & Mood Matrix

A productivity task manager based on the **Eisenhower Matrix** with mood tracking.

The project helps organize tasks based on their urgency and importance while also allowing users to track their mood and productivity.

## ✨ Features

- 📌 Organize tasks into 4 Eisenhower Matrix quadrants
- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔍 Search and filter tasks
- 🖱️ Drag and drop tasks between quadrants
- 📊 Live task counters for each quadrant
- 🕒 Relative task timestamps
- 😊 Mood tracking
- 🔔 Toast notifications for user actions
- ↩️ Undo deleted tasks
- 💾 Persistent data using Local Storage
- 🌙 Dark glassmorphism UI

## 🗂️ Eisenhower Matrix

| Quadrant | Category | Description |
|---|---|---|
| Q1 | Do First | Urgent & Important |
| Q2 | Schedule | Important, Not Urgent |
| Q3 | Delegate | Urgent, Not Important |
| Q4 | Eliminate | Not Urgent or Important |

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- HTML5 Drag & Drop API
